# MUK branding asset

`assets/muk-logo.png` is the unaltered official transparent German-language MUK logo, downloaded on 7 October 2026. It contains the complete wordmark and university name. Native dimensions: 1000 × 322 pixels; 48,235 bytes.

- Official source page: <https://muk.ac.at/die-muk/presse/download-center/logos-der-muk.html>
- Direct PNG: <https://muk.ac.at/fileadmin/mediafiles/images/Logos/MUK/MUKlogo_main_72dpi_rgb_rot.png>
- SHA-256: `2fad1836ae5c0ca113de46bf806e2483e9f86af912072172a5e321e5b7995a2b`

The source page restricts the university logo to university purposes. This project uses it for Adrián Artacho’s university teaching tool; the logo is not covered by any license for the application’s original code. Preserve the logo’s proportions, transparency, internal padding, and complete university name.

Suggested alternative text: “MUK — Musik und Kunst Privatuniversität der Stadt Wien”.

## Interface palette

The university’s current public website stylesheet uses `#c01111` as a red accent and `#a11213` for selected elements and backgrounds, alongside white and graphite (`#333333`). These are observed website colors, not a claim to a comprehensive official brand manual. The original PNG contains Adobe RGB color-profile metadata and its solid red pixels have channel values `#a01414`; preserve its original profile rather than recoloring it to a CSS swatch.

Stylesheet inspected: <https://muk.ac.at/typo3temp/assets/compressed/merged-2b2a247ecdaa3a096f1b48a77804239f.css?1782330090>

The application can use white or warm off-white surfaces, graphite type, and a restrained university red accent. Give the selected temperament a colored line and the 12-EDO reference a neutral/dashed line; always distinguish them with labels and line style as well as color.
